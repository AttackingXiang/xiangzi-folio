这是一份贴近 Folio 实际产品界面的视觉资产索引，集中整理了主流图标、主题配方、文件夹样式、按钮层级和截图证据。展示页直接引用工程内的 Phosphor Icons、15 套主题 token 和实际产品语气，适合作为后续页面、设置项和新主题的起始参考。

## 快速入口

启动本地开发服务后打开：

```text
http://127.0.0.1:4173/design-system
```

展示页支持：

- 点击主题卡片切换舞台预览和当前强调色。

- 点击按钮查看选择态、主次层级和交互规则。

## 推荐默认主题配方

主题不是单独替换一组颜色，而是一组完整的产品语气。下面的配方把背景、表面、文件夹、密度和按钮组合放在一起。

| 配方 | 适合人群 | 背景与表面 | 文件夹样式 | 密度 | 按钮组合 |
| --- | --- | --- | --- | --- | --- |
| 北欧晨光 / 清爽默认 | 办公、日常书签 | 冷白雾蓝 + 柔和玻璃 | 完整目录 | 舒适 | 主按钮 + 柔和次按钮 |
| 晨雾玻璃 / 轻盈收藏 | 日常、灵感收集 | 奶油薄荷 + 半透明表面 | 混合组件 | 舒适 | 图标按钮 + 轻量链接 |
| 象牙纸感 / 编辑阅读 | 写作者、研究者 | 暖纸白 + 墨色 | 双栏阅读 | 舒适 | 描边按钮 + 文本操作 |
| 轨道工坊 / 沉浸工作台 | 开发者、效率用户 | 摄影蓝灰 + 低对比玻璃 | 重点收藏 | 紧凑 | 高对比主按钮 + 工具组 |
| 暮色空间 / 创意聚焦 | 设计师、创意用户 | 蓝紫黄昏 + 深色玻璃 | 紧凑堆叠 | 紧凑 | 强调色按钮 + 选择态 |
| 清晰高对比 / 无障碍优先 | 低视力、专注用户 | 高对比白 + 无模糊 | 图标宫格 | 舒适 | 明确文字按钮 + 状态反馈 |

当前产品默认使用“北欧晨光”。“轨道工坊”保留为极客用户的优先推荐，透明文件夹可作为上述任意配方的独立变体。

## 主流图标索引

图标库：`@phosphor-icons/react`。

| 分类 | 典型图标 | 主要用途 |
| --- | --- | --- |
| 导航与层级 | 首页、探索、文件夹、书签、网格、列表、堆叠、返回 | 页面入口、目录关系和内容层级 |
| 操作与编辑 | 新增、编辑、复制、下载、上传、刷新、删除、链接 | 明确的 CRUD、同步和外部链接动作 |
| 系统与状态 | 设置、筛选、通知、完成、信息、警告、隐私、锁定 | 设置项、反馈、权限和风险提示 |
| 内容与工作 | 文档、笔记、日历、数据、报表、桌面端、移动端、云端 | 工作台、资料和设备入口 |
| 品牌与工具 | Figma、GitHub、网页、终端、代码、全球、相机、创意 | 来源识别、品牌入口和工具语气 |

### 图标尺寸规则

| 尺寸 | 建议场景 | 默认 weight |
| --- | --- | --- |
| 16 px | 行内状态、辅助信息 | `regular` |
| 20 px | 常规按钮、菜单项 | `regular` |
| 24 px | 快捷入口、卡片图标 | `regular` 或 `duotone` |
| 32 px | 空状态、特性说明 | `duotone` |
| `fill` | 仅用于品牌标记、选中态或强状态 | 谨慎使用 |

### 图标使用边界

1. 没有稳定语义的动作不要只放图标；应补充文本、tooltip 和 `aria-label`。
2. Figma、GitHub 等品牌图标只表达来源，不代替“打开、编辑、删除”等通用操作。
3. 同一组控件保持同一 optical size 和 weight，不要在一个按钮组里混用过多风格。
4. 成功、信息、警告使用固定语义颜色；主题强调色负责品牌和主要动作，不替代风险颜色。

## 功能按钮组合

| 层级 | 适合场景 | 视觉规则 | 示例 |
| --- | --- | --- | --- |
| 主要动作 | 当前区域最重要的下一步 | 强调色填充、白色文字、轻微投影 | 新建书签、保存更改、打开链接 |
| 次级动作 | 仍然重要但不应抢主任务 | 描边或浅色表面、强调色文字 | 编辑、导出、调整显示 |
| 低强调动作 | 取消、更多、隐藏等上下文操作 | 透明背景、弱文字、无明显投影 | 取消、更多、隐藏背景 |
| 图标动作 | 高频且语义稳定的短动作 | 固定尺寸、必须有可访问名称 | 搜索、收藏、设置 |

默认按钮组合建议：

```text
主按钮 1 个
次级按钮 0–2 个
低强调按钮 0–2 个
图标按钮按语义成组，不单独承担不可逆操作
```

## 文件夹框与透明变体

“透明背景”是文件夹级配置，不会改变文件夹内部的书签布局、宽度或折叠状态。

- 普通文件夹：去掉卡片填充和大面积阴影，保留标题区轻微表面。
- 快捷书签：去掉外层 shelf 填充，但保留入口卡片本身的可点击表面。
- 深色主题：透明后仍使用边界色和标题层级，避免文件夹与壁纸完全融为一体。
- 明亮主题：透明后减少边框强度，依靠标题、favicon backing tile 和间距区分层级。

使用入口：编辑模式 → 文件夹“设置显示样式” → “透明背景”；也可以打开文件夹编辑弹窗使用同一开关。
